# CivicTrack — Frontend

Next.js 16 (App Router) + TypeScript + Tailwind frontend for CivicTrack.

See the [root README](../README.md) for what this project does and
how to run the full stack, and [ARCHITECTURE.md](../ARCHITECTURE.md)
for how the pieces fit together.

## Local development

```bash
cp .env.example .env.local   # set NEXT_PUBLIC_API_URL
npm install
npm run dev
```
